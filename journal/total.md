# À quoi servent les résultats N et P
1-D'où viennent l'azote et le phosphore ? Agriculture, population, eaux usées, élevage, etc.
2-En quelles quantités ? Combien de kg ou de tonnes de N et P sont produits, utilisés ou rejetés chaque année ?
3-Ou se trouvent-ils ? Dans quelles communes ou quels territoires les flux sont-ils les plus importants ?
4-Que peut-on améliorer ? Réduire les pertes, mieux valoriser les nutriments et identifier les possibilités de recyclage.

## Rôle des différentes sources et composantes du projet CAFÉ

| Élément | Rôle dans CAFÉ |
|---|---|
| Niveau administratif | Définit l'échelle d'analyse : commune, intercommunalité, département, etc. |
| Commune | Unité géographique permettant de relier les données grâce au code INSEE. |
| COG / ADMIN EXPRESS | Fournit les identifiants et les limites administratives nécessaires aux analyses spatiales. |
| Assainissement | Décrit la collecte et le traitement des eaux usées. |
| SISPEA | Fournit des informations sur les services publics d'eau et d'assainissement, leurs performances et leurs caractéristiques. |
| Base assainissement | Fournit des données sur les systèmes et stations de traitement des eaux usées. |
| Agriculture | Représente les surfaces cultivées et les besoins agricoles en nutriments. |
| RPG | Identifie les parcelles agricoles, les cultures et leurs surfaces. |
| Engrais | Représente les apports fertilisants à estimer à partir des surfaces, cultures et coefficients adaptés. |
| Population | Représente les personnes présentes ou résidentes sur le territoire. |
| INSEE | Fournit les données démographiques et territoriales. |
| Fichier / Mélodi / pynsee | Trois moyens d'accéder aux données INSEE : téléchargement, service de données et bibliothèque Python. |
| Élèves | Population spécifique utile pour estimer les présences et les excrétions dans les établissements scolaires. |
| Excrétions | Quantités d'azote et de phosphore rejetées par les humains, notamment dans l'urine et les matières fécales. |
| Impacts environnementaux | Résultats à évaluer : pressions sur l'eau, pertes de nutriments, émissions et autres impacts pertinents. |
